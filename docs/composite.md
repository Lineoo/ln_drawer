## 颜色空间表示

用一下记法声明颜色空间

- 用 `L` 表示原始线性的RGB色彩
- 用 `P` 表示进行 Alpha 预乘
- 用 `S` 表示进行 gamma 编码

这种记法下：

- `S(L)` 表示 srgb 色彩，也是显示器期望的颜色
- 感知混合 `P(S(L))` 和光学混合 `P(L)` 进行 alpha 预乘考虑贡献
- PNG 格式保存的内容是 `S(L)` 也就是 gamma 编码非预乘


## 重要的色彩空间规定

色彩通道
- 画布，使用 `S(P(L))`
- 渲染表面，使用 `P(S(L))`
- Shader 输出，使用 `P(L)` 或者 `L`
- Shader 输入，使用 `P(L)` 或者 `L`

在光学线性（linear-srgb）`P(L)` 混合的：

- 画布渲染采样（硬件 sampler）
- mipmap 合成（`mipmap.wgsl`）
- 渲染组件的合成（通道 blending）
 
在感知线性（srgb）`P(S(L))` 混合的：

- 画布和背景图案（`render.wgsl`）
- 笔刷和画布（笔刷自带与 `merge.wgsl`）
- 图层之间合并（`merge.wgsl`）
- 矢量图形（还没做）

## 颜色行为

### 1. 画布存储

存储的是：`S(P(L))`

PNG 格式存储的是 `S(L)`，两者需要进行格式转换，并且我们的区块不能够完美存储所有数据。

### 2. {brush}/merge.wgsl

1. 笔刷颜色 `S(L)` 针对 alpha 通道添加遮罩，然后转换成 `P(S(L))`
2. 读取画布颜色 `S(P(L))` 转换成 `P(S(L))`
3. `P(S(L))` 感知混合
4. 转换回 `S(P(L))` 存储

### 3. mipmap.wgsl

1. 读取画布颜色 `S(P(L))`，解 gamma 变成 `P(L)`
2. `P(L)`光学混合
3. 编 gamma 变成 `S(P(L))` 存回去

### 4. render.wgsl

1. 直接采样得到的就是光学混合过滤好的 `P(L)`
2. 转换成 `P(S(L))`
3. 和背景纹样进行 `P(S(L))` 感知混合，直接 replace 输出
